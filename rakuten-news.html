အရေးကြီးသတိပေးချက်

Rakuten Securities တွင် မသင်္ကာဖွယ် ဝင်ရောက်မှု ဖြစ်ပွား၊ သုံးစွဲသူများ ၂ ဆင့်ခံစနစ် (2段階認証) အမြန်ဆုံး ဖွင့်ထားရန် သတိပေး

ထုတ်ပြန်ချိန် - ၂၀၂၆ ခုနှစ် | WYT News အထူးသတင်း

ဂျပန်နိုင်ငံ၏ ထိပ်တန်း အွန်လိုင်းစတော့ရှယ်ယာ ရင်းနှီးမြှုပ်နှံမှု ပလက်ဖောင်းတစ်ခုဖြစ်သည့် Rakuten Securities (楽天証券) ၏ စနစ်အတွင်းသို့ မသမာသူများမှ ခွင့်ပြုချက်မရှိဘဲ ဝင်ရောက်ရန် ကြိုးပမ်းမှုများ တွေ့ရှိခဲ့ရကြောင်း သက်ဆိုင်ရာကုမ္ပဏီက တရားဝင် သတိပေးချက် ထုတ်ပြန်ထားပါသည်။

သုံးစွဲသူများ၏ Login ID နှင့် စကားဝှက်များကို အခြားဝက်ဘ်ဆိုက်များမှ ပေါက်ကြားလာသော ဒေတာများနှင့် တိုက်ဆိုင်စစ်ဆေးကာ ဖောက်ထွင်းရန် ကြိုးစားနေခြင်းဖြစ်ပြီး၊ ငွေကြေးဆုံးရှုံးမှု မဖြစ်ပေါ်စေရန်အတွက် 2段階認証 (၂ ဆင့်ခံ စစ်ဆေးအတည်ပြုခြင်းစနစ်) ကို မဖြစ်မနေ အသက်သွင်းထားကြရန် တိုက်တွန်းထားပါသည်။

💡 2段階認証 (၂ ဆင့်ခံ အတည်ပြုစနစ်) ဆိုသည်မှာ အဘယ်နည်း?

ပုံမှန်အားဖြင့် ID နှင့် Password သာ ရိုက်ထည့်၍ အကောင့်ဝင်ရောက်နိုင်သော်လည်း၊ 2段階認証 ဖွင့်ထားပါက စကားဝှက်အပြင် မိမိဖုန်းနံပါတ်သို့ SMS ဖြင့် ပို့ပေးသော ဂဏန်း ၆ လုံးကုဒ် (သို့မဟုတ် Passkey စနစ်) ကိုပါ ထပ်မံရိုက်ထည့်ရသည့် စနစ်ဖြစ်ပါသည်။ ထို့ကြောင့် သူတစ်ပါးက မိမိ၏ Password ကို သိသွားလျှင်ပင် ဖုန်းမရှိဘဲ အကောင့်ထဲသို့ လုံးဝ ဝင်ရောက်နိုင်မည် မဟုတ်ပါ။

🛠 Rakuten Securities တွင် 2段階認証 ဖွင့်နည်း (အဆင့်ဆင့်)

  1. Rakuten Securities ထဲသို့ Login ဝင်ပါ: ဝက်ဘ်ဆိုက် သို့မဟုတ် iSPEED အက်ပ်မှတစ်ဆင့် မိမိအကောင့်ထဲသို့ ဝင်ရောက်ပါ။
  2. Setting သို့ သွားပါ: ညာဘက်အပေါ်ထောင့်ရှိ 「マイメニュー」 (My Menu) ကို နှိပ်ပြီး 「お客様情報 設定・変更」 (Customer Info Settings) သို့ ဝင်ပါ။
  3. Security ကဏ္ဍကို ရွေးပါ: 「セキュリティ」 (Security) ကဏ္ဍအောက်ရှိ 「2段階認証」 နေရာသို့ သွားပါ။
  4. စနစ်ကို စတင်ဖွင့်ပါ: 「設定する」 (သို့မဟုတ် 変更) ကို နှိပ်ပြီး အတည်ပြုကုဒ် လက်ခံမည့် ဖုန်းနံပါတ် (SMS) သို့မဟုတ် အီးမေးလ်လိပ်စာ ကို ရွေးချယ် အတည်ပြုပေးပါ။
  5. Passkey တွဲချိတ်ခြင်း: ပိုမိုလွယ်ကူပြီး လုံခြုံမှုရှိစေရန် iPhone ရဲ့ Face ID / Touch ID ဖြင့် တိုက်ရိုက်ဝင်နိုင်သည့် Passkey စနစ်ကိုလည်း တစ်ပါတည်း ဖွင့်ထားနိုင်ပါသည်။

ဂျပန်နိုင်ငံတွင် NISA သို့မဟုတ် စတော့ရှယ်ယာ စုဆောင်းနေကြသော မြန်မာနိုင်ငံသားများအနေဖြင့် မိမိတို့၏ ငွေစုငွေရင်းများ ဘေးကင်းလုံခြုံစေရန်အတွက် ယခုချက်ချင်းပင် အဆိုပါ လုံခြုံရေးစနစ်ကို ဖွင့်ထားရန် အကြံပြုအပ်ပါသည်။
